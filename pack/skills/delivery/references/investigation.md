# 调查阶段规则

协调者维护 `02-investigation/README.md`（调查总览）。调查只记录**能证明的事实**和**尚未证明的未知**，不替需求做决定，也不写设计方案。

## 正文结构

```markdown
# 调查

## 事实

### <事实标题>

- 证据：<工程相对路径>#<定位>
- 说明：

## 未知

### <问题>

- 影响：
- 阻塞：是或否
```

- 「证据」相对路径必须在 Unity 工程内存在。
- 没有未知时保留「## 未知」，正文写「无」。
- 可以引用需求里的场景名帮助读者对应，**不得**改写需求正文。

## 并行只读（协调者）

多个互不依赖、只读、能各自交回证据的问题，可以由协调者分多次只读查看工程；**写入**调查总览仍由当前对话串行完成。本版本不启动并行子 Agent 或子进程。

## 阻塞

存在「阻塞：是」的未知项时，不能记录设计评审，也不能通过 `design-ready`。先消减阻塞未知或改为「否」并说明依据，再进入设计评审。
